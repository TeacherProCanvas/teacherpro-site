✨ Features That Save Time

📅 Smart Course Scheduling

Build your course schedule once, apply it everywhere. Set blackout dates, preview changes, and bulk publish/unpublish with one click.

📊 Grading Power Tools

Quick-fill grades, apply defaults, and attach rubrics instantly. Use a reusable feedback library for consistent, personalized comments.

⚙️ Course Management Made Simple

Edit multiple assignments at once, post announcements to dozens of courses, and manage navigation tabs in seconds.

💬 Discussion & Session Tools

Flag student posts, organize discussion boards, and view today's live sessions directly from your dashboard.

🚀 Get Started in Minutes

  1. Install from the Chrome Web Store
  2. Pin the extension to your toolbar
  3. Enter your Canvas Base URL
  4. Generate your Canvas Access Token
  5. Start saving hours every week
